# Assembly Language Programming (x86 - 32-bit) using GNU Assembler (GAS)

This repository contains programs, assignments, notes, and classwork developed during the **Assembly Language Programming** course in **2026**.

## Development Environment

* Operating System: Ubuntu 21.04
* Architecture: x86 (32-bit)
* Assembler: GNU Assembler (GAS)
* Linker: GNU Linker (`ld`)

## Installing 32-bit Development Support

On a 64-bit Ubuntu system, install the required packages to compile and link 32-bit applications:

```bash
sudo apt install gcc-multilib libc6-dev-i386
```

This installs:

* `gcc-multilib` – Enables building 32-bit binaries.
* `libc6-dev-i386` – Provides 32-bit C libraries and development headers.

## Build Process

Assembly source files are written manually in `.s` files. For many examples, an equivalent `.c` file is also maintained for reference and understanding.

### Assemble

```bash
as filename.s --32 -o filename.o
```

### Link
```bash
ld filename.o -m elf_i386 -lc -dynamic-linker /lib/ld-linux.so.2 -e main -o filename
```

## Naming Convention

* `.c` → Reference C implementation.
* `.s` → Handwritten assembly source.
* `.o` → Object file generated by the assembler.
* Executable → Final linked binary.

Each `dayN` directory contains examples, assignments, and class exercises covered during that day of the course.
